# Kenangan · Sacred Luxe - Kategori Adat
## Design Specification

### Aesthetic: Neo-Adat Noir "Sacred Luxe"

### Color Tokens
- --bg: #0A0A08 (Deep Obsidian)
- --surface: #121210 (Charcoal)
- --gold: #C9A84C (Antique Gold)
- --gold-light: #E8D5A0 (Champagne)
- --text: #F0EDE6 (Ivory)

### Typography
- Display: Cormorant Garamond (Serif)
- Body: Inter (Sans-serif)
- Script: EB Garamond (Quotes, Arabic)

### Sections
1. Cover - Countdown, names with shimmer
2. Greeting - Bismillah, guest name
3. Couple - Photo frames, parents info
4. Event - Map with Neo-Noir filter
5. Gallery - Horizontal snap scroll
6. RSVP - Form with gold inputs
7. Gift - Bank card copy
8. Closing - Quran verse, hashtag

### Ornamental Motifs
- Javanese Kawung (harmony)
- Balinese Canang Sari (balance)
- Sumatran Bundo Kandis (royalty)

### Effects
- Gold shimmer animation
- Noise texture overlay
- Vignette gradient
- Corner ornaments
