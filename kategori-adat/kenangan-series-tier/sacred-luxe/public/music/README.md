# 🎵 Folder Musik Undangan

Taruh file musik lagu di sini dengan nama:

```
background.mp3
```

## Cara pakai:
1. Cari lagu MP3 yang ingin dipakai (contoh: "A Thousand Years - Christina Perri")
2. Rename filenya menjadi `background.mp3`
3. Copy ke folder ini: `public/music/background.mp3`
4. Refresh browser — music player akan muncul otomatis

## Tips:
- Format yang didukung: `.mp3`, `.ogg`, `.wav`
- Ukuran disarankan: < 5MB untuk loading cepat
- Kalau mau ganti nama lagu di player, edit `src/components/MusicPlayer.tsx` baris song info

## Konversi / Download MP3:
- YouTube to MP3: yt-dlp, y2mate, dll
- Potong durasi: ffmpeg, Adobe Audition, Audacity
