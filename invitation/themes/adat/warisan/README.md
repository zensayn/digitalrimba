## Panduan Menambah Tema Baru

1. Buat folder baru: `mkdir nama-tema`
2. Init Next.js: `cd nama-tema && bun x create-next-app@latest ./`
3. Salin `DESIGN_SPEC.md` sebagai referensi
4. Tambahkan baris baru di tabel di atas
