# Warisan · Kategori Adat
## Design Specification

> **Tier 3 — Premium · Rp 700rb**
> "Diwariskan untuk generasi."

---

### Aesthetic: "Sacred Heritage"

Timeless seperti naskah kuno, monumental seperti arsitektur keraton. Warisan adalah tier tertinggi — setiap elemen dirancang dengan presisi dan kemewahan yang tidak terlihat di tier lain. Undangan ini bukan hanya untuk dibuka sekali, tapi untuk dikenang lintas generasi.

11. Closing — Ayat + doa + family signature

---

### Animation Style

- Cinematic reveal: opacity + scale dari 0.9→1
- Parallax scroll pada background elements
- Stagger: 0.2s per item
- Durasi transisi: 0.9s easeOutQuint
- Particle/dust effect ringan (opsional)

---

### Ornamental Elements

- Motif ukiran keraton (SVG detailed)
- Double gold border dengan corner ornamen
- Kaligrafi dekoratif
- Tanda tangan / cap keluarga
- Wax seal effect

---

### Premium Features (eksklusif tier ini)

- Video background loop di Cover
- QR code per tamu untuk check-in
- Multi-bahasa (Indonesia + English)
- Custom domain siap pakai
- Unlimited tamu (URL ?to=)
- Print-ready PDF version
